## v3.5 verifier 的具体化（backlog 条款 → 可实施规格）

v2（全禁具体值）→ cat3 只救回 3/14 L2；v3（模型自判蕴含）→ +10.4pp 但
cat5 漏 ~6。v3.5 = **词法归属闸**：推断尾允许点名的值，必须其区分性
token 逐字出现在**本题绑定的前提记录**里（不是全记忆、不是全会话）。

- cat3 侧预期救援 ≈ 8-13 题（10 归属 + partials：school/four 等推理值）
- cat5 侧预期泄漏 ≈ v3 量级：危险不在编造值（编造值不可能归属），而在
  **错配**——值在记录里但属另一前提（fashion-dept 型）。收敛手段：
  归属范围从"全会话记录"收紧到"assist 阶段为该题绑定的前提记录集"，
  减少跨主题错配面。这是 v3.5 相对 v3 理论上更严的那一档。
- 零增量 LLM 成本：检查是子串/token 判断，运行时不用模型。

## cat3 天花板（记录-only 立场下的诚实账）

41.7% + v3.5 ~8-13 题 → **≈50-55%**。要更高必须动立场：
- **L1（~20 题）**：要"记录描述在、名字靠世界知识补"模式——这正是
  cat5 防线哲学反对的方向，但判别线其实可分：描述在记录里 vs 完全捏造。
  属研究立场决策，非代码缺陷。
- **L4（~14 题）**：判官口径问题（倾向对/另有合理答算错）——换宽松
  rubric 或训练答案贴近 gold 词形，属测量学。

**结论**：cat3 主攻的真实弹药 = v3.5 词法归属闸（+~8-13 题到 ~50-55%）+
锚解析小修；再往上是立场题（世界知识放行）和测量题（rubric），不是
记忆系统病灶。"多跳检索"方向被数据否定——材料几乎全部已在记录里。

## 附：v3.5 grounded_lex 评测结果（208 题切片实测）

| 臂 | cat3 (96) | cat5 (112切片) |
|---|---|---|
| grnd2 = v2 部署档 | 40/96 = 41.7% | 103/112 = 92.0% |
| grnd3 = v3 蕴含闸 | 44/96 = 45.8% | 99/112 = 88.4% |
| **grndlx = v3.5 词法归属** | **42/96 = 43.8%** | **94/107 = 87.9%** |

**裁决：v3.5 双轴不达标，v2 档保持部署。**

- cat3 逐题 diff：+10 救回 / −8 回退。救回数符合解剖预测（~10 道归属残错），但回退抵消——SPLICED/NO_PREMISE 过度拒答 ~3（合成题被闸条款带得更保守）、infra 1、推断值变差 ~2、判官噪声 ~2（同型答案两判翻转）。
- cat5 泄漏形态确认设计前提错误：全部漏题为 GROUNDED_OK 推断尾点名**归属值**（"Sara Bareilles"/"his family"）——闸按要求放行了逐字在记录中的值，但对抗题上点名**任何**具体值都算漏（对抗前提本身不成立，正解应完全拒答）。归属判别（答案值在不在记录里）不能区分两题型，因为漏题不需要点名 gold——记录里有成千上万个归属值可点。
- **真判别器在前提层不在答案层**：cat3 L2 与 cat5 的分界是"问题所问事件是否被记录"，不是"所答值是否被记录"。事件级归属检查需持久化 verify 绑定前提（当前 arm 行未存）——作为后续设想挂 backlog，不立刻再跑臂。
- 四臂净账：v1 +10.4/−6.3 漏 → v2 +6.3/+0.9（部署）→ v3 +10.4/−3.6 漏 → v3.5 +2.1/−4.1 漏。闸线收敛：v2 为该机制族局部最优。

## 前提级归属闸可行性分析（离线代理，2026-10-03）

**问题**：前提级归属（"问题所问事件是否在记录里"）能否区分 cat3-L2 与 cat5？
离线代理：问题内容 token 全数出现在该会话对话文本 = 前提归属。

**结果**（v2 部署臂 208 题）：
- cat3 错 56：归属 27 / 不归属 29（归属面比 L2 解剖的 ~13 大——token 代理粗糙，部分命中不代表前提成立）
- cat5 错 9：归属 6 / 不归属 3
- cat5 对 103：归属 63 / 不归属 40

**结论：前提 token 归属本身判不开。** 但归因发现真因：

cat5 的 6 道"归属但答错"中，4 道是**已知误标簇**（c0_q161 手绘碗、c0_q184 吉他、c0_q188 徒步、c2_q186 5K 慈善跑）——事件真实存在于记录，正解本应回答，基准把"拒答"当 gold。另外 c0_q166/167 是措辞擦边。**v2 的 9 道 cat5 残错 ≈ 3 真漏 + 4-6 误标 + 2 边界**——前提闸解决得了 3 道真漏（前提不归属），但救不了也无需救误标题（答了本来是对的）。

**净含义**：事件级归属闸的期望上限 = 3 道 cat5 真漏的修复空间，且 cat5 有效天花板被误标压在 ~93%（判官口径下）。叠合 v3.5 实测（答案侧归属已救回 L2 但带上 cat5 新漏），前提层闸相对 v3.5 增量有限——**backlog 项降级为低优先**，前提分析使能件（verify atoms 持久化）已入档备用。
